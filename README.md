# The Family Daily — Kitchen E-ink Board Guide

A friendly, public tutorial for building a newspaper-style family kitchen board on a **Hokku / Huessen 13.3″ Spectra 6** e-ink frame, with **Google Calendar** as the calendar source.

**Live guide:** [https://zalberico.github.io/family-eink-guide/](https://zalberico.github.io/family-eink-guide/)

Also may be reachable at [https://zalberico.com/family-eink-guide/](https://zalberico.com/family-eink-guide/) if that custom domain is wired to Pages.

## What's in here

- `index.html` — long-form tutorial (GitHub Pages site root)
- `assets/sample-board.svg` — fictional sample board mock (Alex & Sam)
- `assets/architecture.svg` — pipeline diagram

## Privacy

This repo teaches a **pattern**. It does **not** include real household schedules, Wi‑Fi secrets, LAN IPs, tokens, chat logs, or screenshots of a live board. Use placeholders locally (`YOUR_WIFI`, your own calendar credentials).
