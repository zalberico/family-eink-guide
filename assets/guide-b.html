Inputs & collectors

Calendar, email, iMessage, and WhatsApp are first-class inputs — not optional add-ons. Grok Bot implements collectors as small scripts that emit JSON for the HTML template (not “scrape a logged-in browser forever” as the primary path). Human: complete the logins when asked.

InputWhat it feedsBot wiring (human logs in)
Shared family calendar Coming up Google Calendar API or private iCal URL (Raf-style Google households); Apple Calendar / CalDAV fine. Dedicated family calendar — not work.
Email Packages, school/appt mail → Changes Fastmail, Gmail, or iCloud via API / IMAP. Filter: tracking, school notices, appointment confirmations — not the whole inbox on the wall.
iMessage + WhatsApp Live Wire (household logistics) Local read-only collectors on the always-on host (or a bridge the bot sets up). Kitchen-safe paraphrases. Chat is input, not bot command authority (except named owners).
Weather Masthead strip Public weather API with a local key in env — fictional sample shows “68° Partly cloudy.”
Optional Reminders, invites Apple Reminders / system reminders, Partiful-style feeds if you use them. Structured JSON in, kitchen-safe copy out.

Collector pattern — Grok Bot builds this

  1. Each collector writes JSON under a local data dir (e.g. ~/.config/family-daily/), gitignored.
  2. Secrets in env / OS keychain (e.g. FAMILY_ICAL_URL=…/private-PLACEHOLDER/basic.ics).
  3. Newspaper template reads only those JSON files. Collector failure → publish hard-fails (no half-blank edition).
  4. Changes = useful deltas only (soccer moved, package expected). Skip “nothing changed” filler.
# Pseudocode shape — Grok Bot writes the real scripts
# collectors/calendar.py → events.json
# collectors/email.py    → packages_and_school.json
# collectors/chat.py     → live_wire.json   (paraphrased, kitchen-safe)
# collectors/weather.py  → weather.json
# render/edition.html + headless Chrome → family-daily.png (1200×1600)
# publish/verify: convert==ok && show_next pinned && mtime fresh

Frame not updating

The kitchen frame is not updating. Diagnose end-to-end yourself:
- Is hokku-server up? Local UI reachable?
- Did the last publish verify (mtime, convert==ok, show_next)?
- Are refresh_image_at_time values AFTER the publish cron/launchd jobs?
- After a wake window, did last_seen update?
Fix the root cause, re-publish a test edition, and report what you verified.
Only ask me if you need a Wi-Fi password or account re-login.

Tweak layout / editorial

Adjust the Family Daily HTML: stronger Coming Up from the shared calendar,
Changes only for real deltas (moved events, packages, confirmations),
keep Live Wire to 3 short lines. Preserve 1200×1600 and ~40px margins.
Re-render, publish, verify convert + show_next.

Editorial & privacy

  • Audience: people glancing while making coffee — not ops dashboards.
  • No secrets on the wall: no passwords, pay, brokerage, account numbers, medical detail, caregiver schedules.
  • Changes: useful deltas only. Skip “nothing changed” filler.
  • No ops jargon on the paper (“pipeline green” belongs in logs, not breakfast).
  • Coming up: calendar-driven (Google for Raf; Apple Calendar fine too).
  • Mail & chat: first-class inputs → short kitchen copy — not a dump of inbox or group chat.
  • Command authority: chat does not control Grok Bot unless you name owners who may.
  • Resolved loops: let finished items decay in about 1–2 days.
  • Correctness before publish: collector failure → fail loud on the host, don’t pin a half-blank edition.

Hardware facts (for the bot)

Troubleshooting

Paste the “Frame not updating” prompt to Grok Bot. The bot should own diagnosis; you only re-enter Wi‑Fi or re-login if asked.

SymptomGrok Bot should…
Frame never updates Confirm server up; wake times after publish; same LAN; check last_seen after a wake window.
Image looks cropped Fix scale-to-fill / margins (~40px); stick to 1200×1600; re-publish and verify.
Convert status not ok Hard-fail publish; inspect PNG; re-render; do not pin show_next until ok.
Calendar empty Fix family calendar ID / iCal env; token refresh; don’t fall back to browser scraping as primary path.
Mail / chat missing Confirm collectors ran; credentials valid; filters sensible; paraphrases kitchen-safe. Ask human only for re-login.
Wi‑Fi flash failed Re-read upstream flash docs; pause for human Wi‑Fi entry; check 2.4 GHz vs 5 GHz per Hokku hardware notes.
