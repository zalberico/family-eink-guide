Inputs & collectors

Calendar, email, iMessage, and WhatsApp are first-class inputs—not optional add-ons. Grok Bot builds the collectors; you only log in when asked.

InputFeedsBot builds; you log in
Shared family calendar Coming up Google Calendar API or private iCal (Raf-style Google); Apple Calendar / CalDAV fine. Dedicated family calendar—not work.
Email Packages / school → Changes Fastmail, Gmail, or iCloud. API/IMAP + local token. Filter: tracking, school, appointments—not the whole inbox on the wall.
iMessage + WhatsApp Live Wire Read-only collectors on the always-on host (or bridge the bot sets up). Kitchen-safe paraphrases. Chat is input, not command authority (except named owners).
Weather Masthead Public weather API + local key. Sample: “68° Partly cloudy.”
Optional extras Reminders, invites Reminders / Partiful-style feeds if you use them.

Collector pattern (bot-executable)

  1. Each collector writes JSON under a local data dir (e.g. ~/.config/family-daily/), gitignored.
  2. Secrets in env / keychain — e.g. FAMILY_ICAL_URL=…/private-PLACEHOLDER/basic.ics.
  3. Template reads only those JSON files; collector failure → publish hard-fails.
  4. Changes = useful deltas only.
# Bot writes the real scripts
# collectors/calendar.py → events.json
# collectors/email.py    → packages_and_school.json
# collectors/chat.py     → live_wire.json   (paraphrased)
# collectors/weather.py  → weather.json
# render + headless Chrome → family-daily.png (1200×1600)
# publish/verify: convert==ok && show_next pinned && mtime fresh
Private feeds iCal private URLs, IMAP passwords, and chat bridges stay on your machine (examples use private-PLACEHOLDER).

Editorial & privacy

  • Audience: coffee-glance kitchen, not ops dashboards.
  • No secrets on the wall: passwords, pay, brokerage, medical, caregiver schedules.
  • Changes: useful deltas only.
  • Coming up: calendar-driven (Google for Raf; Apple fine too).
  • Mail & chat: first-class inputs → short kitchen copy.
  • Command authority: chat does not control Grok Bot unless you name owners.
  • Correctness: collector fail → hard-fail publish, don’t pin a blank paper.

Troubleshooting

Prefer the “Frame not updating” prompt. If you’re glancing at logs:

SymptomTell the bot / check
Frame never updatesServer up; wake after publish; same LAN; last_seen after wake.
Cropped imageScale-to-fill without side crop; ~40px margins; 1200×1600.
Convert not okHard-fail publish; re-render; don’t pin show_next until ok.
Calendar emptyCalendar ID / iCal env; token refresh; no browser-scrape primary path.
Mail / chat missingCollector ran; credentials valid; kitchen-safe paraphrases.
Wi‑Fi flash failedBot re-reads upstream docs; you re-enter SSID.
