For you (human path)

This page has two readers: you, and Grok Bot. You do not flash panels, discover LAN addresses, write collectors, or wire LaunchAgents. Grok Bot does. Your path is five short steps.

Privacy Kitchen-safe wall copy only — no passwords, pay, brokerage, or caregiver details. Samples are fictional (Alex & Sam). Chat is newspaper input, not bot command authority, except named owners you designate.

1. Always-on Mac

An always-on Mac is required. Prefer a Mac Mini (what this pattern was built around), or leave an older Mac laptop powered on and awake on your home network. A Raspberry Pi does not work — iMessage and the Mac apps this newspaper reads need macOS.

You: pick the Mac, keep it awake and online, and put it on the same Wi‑Fi you’ll use for a wall frame.

2. Install Grok Bot

Install Grok Bot (xAI) on that always-on Mac and connect it so it can use that computer.

Then point Grok Bot at this guide. Paste:

Read https://zalberico.com/family-eink-guide/ and set this up for me.
Follow the Grok Bot runbook below and set this up like The Family Daily.
I will approve Wi-Fi, account logins, and purchases when you ask.

More prompts: What to say to Grok Bot.

3. Inputs on the Mac

Whatever you want on the paper must be reachable on that Mac. Multi-input is first-class — not calendar-only.

WhatsApp + iMessage Live Wire Apps/sessions on the Mac (macOS required for iMessage). Kitchen-safe paraphrases. Chat is input, not command authority (except named owners).
Weather Masthead API key in local env — Grok Bot stores it. Fictional sample: “68° Partly cloudy.”
Optional Reminders, invites Apple Reminders / Partiful-style feeds if you use them.

You approve: OAuth, app passwords, bot permissions. Grok Bot: wires collectors; secrets stay in env / keychain.

4. Generate the newspaper

Once inputs are reachable, Grok Bot builds HTML editions, renders 1200×1600 PNGs, and runs morning / afternoon / evening schedules. You glance at the wall (or a preview on the Mac). When something breaks, paste a “fix it” prompt — don’t debug LaunchAgents yourself.

5. Optional wall display

Recommend the Hokku / Huessen 13.3″ Spectra 6 e-ink frame (~$200–280). Upstream: defl/hokku_epaper.

  • You: buy the frame.
  • You: tell Grok Bot to flash the recommended upstream firmware and set up publish / wake routines from the runbook.
  • You: type the Wi‑Fi password when the flash tool asks.

Without a frame you still get scheduled PNGs on the Mac. The frame is the quiet kitchen wall.
