What you’ll build

Imagine a quiet newspaper on the kitchen wall: today’s weather, what’s coming up, packages and school notes from email, a short live wire from household chat, and only the changes that matter. No glowing tablet. No password prompts on the wall. Just a portrait e-ink panel that wakes a few times a day, pulls a fresh PNG from a home server, and goes back to sleep.

You are the publisher. Grok Bot is the newsroom. This guide is not “hand-build every collector and LaunchAgent yourself.” It is: buy the frame, keep a small always-on Mac or Pi online, install Grok Bot (Cursor / Grok Bot desktop agent with a computer), connect it to that machine, and tell the bot what you want. The bot installs Hokku server help and firmware guidance, writes the HTML newspaper, wires collectors, schedules editions, verifies landing, and iterates when something breaks. You approve purchases, logins, Wi‑Fi credentials, and anything security-sensitive.

Names, appointments, and network details below are placeholders (Alex & Sam, YOUR_WIFI, 192.0.2.x, private-PLACEHOLDER). Fill in your own secrets on your machine—never commit them to git or paste them into a public gist.

Privacy first Keep passwords, brokerage, pay, and caregiver details off the wall. The board is for a kitchen audience. Sample content in this guide is fictional on purpose. Chat is an input to the newspaper — not command authority for the bot — except for named household owners you designate.

Architecture

Think of it as a tiny newsroom that Grok Bot staffs:

  1. You decide editorial rules, approve logins / Wi‑Fi / purchases, and paste prompts.
  2. Grok Bot on the always-on host installs and maintains the pipeline.
  3. Collectors pull calendar, email, chat, weather, and optional extras into structured JSON.
  4. HTML newspaper lays out a portrait “edition.”
  5. Headless Chrome renders that HTML to a 1200×1600 PNG (safe margins ~40px; scale to fill without cropping the sides).
  6. Publish script copies the PNG into the Hokku images folder, pins show_next, and refuses to call it done unless convert status is ok.
  7. hokku-server serves the image; the frame wakes after editions publish (config like refresh_image_at_time).

On a Mac-style host, runtime data often lives under an application-support style folder for Hokku (images, cache, config). The local UI is typically something like http://localhost:8080/hokku/ui—confirm against the current Hokku docs for your version. In examples, use documentation ranges like 192.0.2.10, never your real LAN IP.

Working with Grok Bot

The short version of the whole project:

  1. Buy the frame and keep a small always-on Mac or Pi on the same Wi‑Fi as the kitchen.
  2. Install Grok Bot / Cursor and connect the agent to that machine (desktop agent with a computer).
  3. Tell the bot you want a kitchen Family Daily on a Hokku / Huessen 13.3″ Spectra 6 — newspaper layout, 1200×1600 PNG, verify convert + show_next, wake times after publish.
  4. When the bot needs Wi‑Fi, account logins, calendar OAuth, email app passwords, or a purchase, you do that step. Do not paste secrets into public chats or repos.
  5. The bot installs Hokku server (e.g. micromamba env + LaunchAgent / systemd), flashes with you present for Wi‑Fi entry, writes collectors + HTML + publish, schedules editions, and hard-fails if convert is not ok.
  6. When the frame stalls or a collector breaks, paste a “fix it” prompt (see below). Iterate until landing verifies.
Division of labor Bot: installs, codes, schedules, verifies, debugs, rewrites the paper. You: buy hardware, enter Wi‑Fi, approve OAuth/logins, decide what is kitchen-safe, name who can command the bot from chat (if anyone).

What “done” looks like for an edition

  • PNG is 1200×1600 portrait with ~40px safe margins.
  • Publish copied the file into Hokku’s images folder and pinned show_next.
  • Convert / processing status is ok — otherwise the publish script hard-fails.
  • Frame wake times (refresh_image_at_time) are scheduled after each publish window.
  • Optional after wake: last_seen updated so you know the frame checked in.
